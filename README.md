配布用テンプレートの原本は、`ptcli` 専用リポジトリの [ptcli/assets/template/](https://github.com/funaryou/ptcli/tree/main/assets/template) に移行しました。今後の文書・スキルの変更は移行先に反映してください。

このディレクトリは既存のファイルとGit履歴を保持するために残しています。CLIは既定でこのディレクトリを参照しません。

利用手順は [ptcli README](https://github.com/funaryou/ptcli/blob/main/README.md) を参照してください。
